# Frozen Artifacts

This directory contains locked (frozen) pipeline artifacts used for regression testing
and reproducibility verification.

## Directory layout

```
frozen/
  <version>/                    # e.g. v1.0.0
    spec.lock.json              # Locked specification snapshot
    manifest.json               # Manifest of expected outputs
    golden/
      <dataset_id>/             # Golden outputs per dataset (added in later steps)
```

## Rules

- **`out/`** directories (`out/`, `backend/out/`) are **ephemeral** and gitignored.
  They are regenerated by pipeline scripts and must never be committed.

- **`frozen/<version>/`** contains intentionally committed artifacts:
  `spec.lock.json`, `manifest.json`, and `golden/<dataset_id>/` outputs.
  These are used as reference baselines for regression tests.

- Frozen artifacts are **updated only intentionally** by creating a new version folder
  (e.g. `frozen/v1.1.0/`). Existing version folders should not be modified after release.

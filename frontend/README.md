# Vue projekt

See mall aitab alustada arendamist Vue 3-ga Vite keskkonnas.

## Soovituslik IDE seadistus

[VS Code](https://code.visualstudio.com/) + [Vue (Official)](https://marketplace.visualstudio.com/items?itemName=Vue.volar) (ja keela Vetur).

## Soovituslik brauseri seadistus

- Chromium-põhised brauserid (Chrome, Edge, Brave jne):
  - [Vue.js devtools](https://chromewebstore.google.com/detail/vuejs-devtools/nhdogjmejiglipccpnnnanhbledajbpd)
  - [Lülita sisse Custom Object Formatter Chrome DevToolsis](http://bit.ly/object-formatters)
- Firefox:
  - [Vue.js devtools](https://addons.mozilla.org/en-US/firefox/addon/vue-js-devtools/)
  - [Lülita sisse Custom Object Formatter Firefox DevToolsis](https://fxdx.dev/firefox-devtools-custom-object-formatters/)

## Konfiguratsiooni kohandamine

Vaata [Vite Configuration Reference](https://vite.dev/config/).

## Projekti seadistamine

```sh
npm install
```

### Kompileerimine ja hot-reload arenduseks

```sh
npm run dev
```

### Kompileerimine ja minimeerimine toodanguks

```sh
npm run build
```

### Unit-testide käivitamine ([Vitest](https://vitest.dev/))

```sh
npm run test:unit
```
